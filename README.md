# JALライフステータスポイント管理ページでできること

JALライフステータスポイントの獲得履歴と、目標までの進捗を確認できる個人用のWebページです。

## 1. ポイントの全体像を確認する

ページ上部に、以下の情報を表示します。

| 表示項目 | 内容 | 現在の登録データでの表示 |
| --- | --- | --- |
| 開始時点 | 月別履歴に含まれない開始時点のポイント | 100 pt |
| 現在の累計 | 開始時点と月別履歴を合算したポイント | 434 pt |
| 次のマイルストーン | まだ到達していない最も近い目標 | 500 pt |
| 次の目標まで | 次の目標に必要な残りポイント | 66 pt |

最終記録の年月も表示します。現在のデータでは2026年8月です。

## 2. 月別の獲得履歴を見る

各月の「航空」「ライフスタイルサービス」「その他」の獲得ポイント、月計、その月までの累計を表で確認できます。

- データは年月順に自動で並びます。
- 登録されていない月は表示しません。
- スマートフォンでは、幅の広い表を横にスクロールできます。

## 3. カテゴリ別の累計を見る

月別履歴に登録されたポイントをカテゴリごとに合計します。

| カテゴリ | 現在の登録データでの合計 |
| --- | ---: |
| 航空 | 205 pt |
| ライフスタイルサービス | 114 pt |
| その他 | 15 pt |
| 月別履歴の合計 | 334 pt |
| 開始時点 | 100 pt |
| 総累計 | 434 pt |

開始時点の100ポイントは、各カテゴリに振り分けずに別枠で扱います。

## 4. マイルストーンへの進捗を見る

設定された500・1,500・3,000・6,000・12,000ポイントの各目標について、以下を表示します。

- 現在の累計ポイント
- 目標までの残りポイント
- 達成率（小数点以下1桁）
- 進捗バー
- 「達成済み」または「未達成」の判定

達成率の表示は最大100%、残りポイントは最小0ポイントです。すべての目標に到達すると、上部に「全達成」と表示します。

## 5. データを追加・修正する

更新は、HTMLファイル内のデータを編集して行います。ページ内の「更新方法」を開くと、追加するデータの書き方を確認できます。

### 新しい月を追加する

`index.html` の `HISTORY` 配列に、次のような1行を追加して保存します。

```javascript
{ month: "2026-09", air: 5, lifestyle: 6, other: 0 },
```

| 項目 | 入力する内容 |
| --- | --- |
| `month` | 年月。例：`2026-09` |
| `air` | 航空で獲得したポイント |
| `lifestyle` | ライフスタイルサービスで獲得したポイント |
| `other` | その他のポイント |

同じ月がすでにある場合は、既存の行を修正します。公開先に変更が反映された後、ページを読み込むと累計や進捗が再計算されます。

### 開始時点や目標を変更する

- `INITIAL_POINTS`：開始時点のポイントを変更します。
- `MILESTONES`：目標ポイントを変更します。

開始時点のポイントと月別履歴に、同じポイントを重複して含めないようにしてください。

## 6. 入力ミスを検出する

以下のようなデータの問題がある場合、集計結果の代わりにエラーメッセージを表示します。

- 年月の形式が正しくない、または月が01〜12の範囲外
- 同じ年月が重複している
- ポイントが負の数、小数、文字列などになっている
- マイルストーンが空、重複、または0以下になっている

ただし、JavaScript自体の文法が壊れた場合（カンマや括弧の欠落など）は、この入力チェックでは検出できません。
このページは、HTMLに記録されたデータを読み込んで表示します。サーバーやデータベース、外部ライブラリは不要ですが、表示にはブラウザーのJavaScriptを使用します。公開したページには、登録された獲得履歴も表示されます。
